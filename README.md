## 📂 Ambientes Disponíveis

- 📁 `Ubuntu-ed/`: Imagem base Ubuntu com ferramentas essenciais pré-instaladas.
- 📁 `alpine-base/`: Ambiente ultraleve baseado em Alpine Linux.
- 📁 `debian-ed-base/`: Sistema Debian configurado para desenvolvimento.
- 📁 `gource/`: Visualização animada da árvore de commits Git via Gource.
